# Monitor Server Frontend

## Project info

**Description**: Monitoring and alerting dashboard for Monitor Server - a real-time server monitoring system

## How to run locally

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Build for production

```sh
npm run build
```

The production build will be in the `dist/` folder.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
